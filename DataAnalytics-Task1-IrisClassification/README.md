# OIBSIP Data Analytics Task 1: Iris Flower Classification

## Project Overview
This project uses Machine Learning to classify Iris flowers into three different species (Setosa, Versicolor, and Virginica) based on their sepal and petal measurements. 

## Tools and Libraries Used
* Python
* Pandas & NumPy (for data manipulation)
* Scikit-Learn (for building the model)
* Matplotlib & Seaborn (for data visualization)

## Models Used
* Logistic Regression
* K-Nearest Neighbors (KNN)

## Results
The models were trained and tested on the classic Iris dataset. 
* **Accuracy:** Achieved approximately 95-100% accuracy (adjust this number based on your actual results).
* The confusion matrix and data visualizations are available inside the notebook.

## How to Run
Open the `notebook.ipynb` file in this folder to view the code and the output plots.
